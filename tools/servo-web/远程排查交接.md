# 远程排查交接：舵机体检、21 号、折叠校准

给另一台电脑上的 Claude Code 看的，人也能照着做。在项目目录里启动 Claude Code，第一句说：

> 先读 tools/servo-web/远程排查交接.md，按里面的流程带我做。

## 你（AI）的角色和规矩

**场景**：这台电脑在同事那儿，鸭子（15 颗飞特 HD-1910）接在这台电脑上。坐在电脑前的是项目主人，远程桌面连进来的；在鸭子旁边动手的是同事，不一定看得到屏幕。

**你带流程，一次只走一步。** 每一步说清楚三件事：

1. 请同事做什么：用主人能直接转述的话
2. 你自己跑什么命令
3. 看到什么算正常，什么不正常

等主人回复再往下。

**规矩**：

1. 全程中文，包括总结。
2. 第 1、2.1、2.2 节只读。**写 EEPROM、开扭矩、让舵机动之前**，先说清楚会发生什么、怎么撤回，等主人明确说「可以」。
3. 不用 FD 的「中位校准」：它只会把当前位置当 2048，在非伸直的姿势点一下零点就错了。
4. 不改代码、不 commit、不 push。发现代码问题记进记录里，主人带回去处理。
5. 每一步做了什么、读到什么，追加到 `tools/servo-web/logs/远程排查-日期.md`。出错写明卡在哪一步，贴原始报错。
6. 串口同一时间只能一个程序用。跑 `servo_report.py` 前关掉调试台（`server.py`）和 FD。

- `pip install -r tools/servo-web/requirements.txt`
- 列串口：`python -c "import serial.tools.list_ports as l; [print(p.device, p.description) for p in l.comports()]"`

**请同事做：**

- **URT-2 先插 USB，再给舵机上电。** 反了总线电平会卡在 2.1 V，一颗都扫不到。
- 说一下供电：电池还是电源、多少伏。电源能限流的话限 2 A。
- 关掉 FD。

## 1. 整机体检（只读，15 颗都接着）

```bash
cd tools/servo-web
python servo_report.py --port COMx
```

把终端输出和 `logs/体检-*.md` 里的红项讲给主人听。重点看：

- 在线几颗，21 号在不在
- 卸载条件 19：过热（4）、过流（8）、过压（1）开没开。出厂一般只有 4
- 状态位 65 有没有亮
- 偏移特别大的（超过 200 步）

扫不到的：先查线和供电；怀疑 ID 不对就加 `--scan-all`。

## 2. 21 号（左髋 roll）

**背景**：同事用 FD 调试时 21 号出了事，断电后舵盘拧不动，怀疑烧了。出厂过流保护默认关着，只开了过热（80 °C）。堵转时一直吃大电流，等不到过热保护动作就可能先坏了。

### 2.1 先比手感（不上电）

请同事断电，用同样的力拧 21 号和 20 号的舵盘。HD-1910 减速比 1:320，好的舵机断电也基本拧不动。

- 20 号也拧不动：手感说明不了问题，接着测
- 20 号能拧、21 号纹丝不动：大概率齿轮崩了卡死，或者关节被别住

### 2.2 单独接上读

请同事把 21 号从腿上拆下来（至少拔掉别的舵机的线），总线上只接它一颗，再上电。

```bash
python servo_report.py --port COMx --ids 21
```

- **PING 不通**：再跑 `--scan-all`，ID 可能变了。还不通，驱动大概率烧了，这颗到此为止，记下来。
- **通了**：看状态位 65 哪一位亮、19、温度、电流、电压。

### 2.3 小幅动一下（要主人同意）

只有 2.2 能读通才做。

```bash
python server.py --port COMx --ids 21
```

主人在浏览器开 http://127.0.0.1:8080：

1. 「单颗操作 → 写寄存器」选 48（转矩限制），值 300（= 30%），**不勾「解锁写」**。48 在 SRAM，断电就恢复。
2. 勾上扭矩。0.15.0 会先把目标对准当前位置，不会动。
3. 滑块往一边拖 50 左右（约 4°），看黄线和电流。

怎么判断：

| 现象 | 结论 |
|---|---|
| 能跟着转 | 舵机本身是好的，问题在关节机械上（装配别住、撞限位） |
| 有电流但不转 | 齿轮卡死 |
| 没电流也不转 | 驱动或电机坏了 |

做完关扭矩，关调试台。21 号要换新的，看第 4 节最后。

## 3. 保护设置（要主人拍板）

体检里 19 缺过流、过压的，按《调试记录》第 5 步应该打开：

- 值 = 原值 + 8 + 1（缺哪个加哪个）。出厂是 4 的写 13。
- 过载（32）要不要也开（出厂 4 → 45），问主人。

方法：调试台「单颗操作」→ 选舵机 →「写寄存器」选 19，填值，**勾「解锁写」**（EEPROM），点写。页面会回读核对。逐颗写。也可以在 FD 编程页勾过流、过压保护再保存。

写完关调试台，重跑一遍整机体检，确认没有红项了。

## 4. 折叠校准（做不做、今天做不做，主人定）

**前提**：15 颗都在线、体检没有红项、调试台是 0.15 起。细节见 [README](README.md) 的一键校准和《调试记录》「缩着能不能当标定基准」一节。

1. 全部关扭矩，鸭子趴在平桌上。3D 叠加选「校准用折叠」，照着摆。
2. 按这个顺序摆。膝在哪碰上跟髋的角度有关，所以先定髋：
   1. 髋 yaw、roll 摆正：腿不外撇、不外张
   2. 髋 pitch：直角尺把大腿摆到跟躯干垂直
   3. 踝 0°：脚板跟小腿成直角
   4. 膝往里折，折到踝刚好贴上大腿上的舵机就停，别顶着使劲
   5. 再用直角尺复查一遍髋
   6. 脖子竖直、头平视朝正前、不歪，嘴闭上
3. 基准选「官方折叠（头颈摆正）」，15 颗全选，点「一键校准」。
   - 确认框里正常每颗差几度。
   - 差 30° 以上的先停，分清原因：装舵盘时转了半圈（照常校），还是 ± 设反了（先核：扭矩关着用手掰一下，看 3D 是不是往同一边转）。
4. 校完读数应该是 22/23 = 1025、12/13 = 3071，其余 2048。
5. 用手把腿展开，托住鸭子，开扭矩（不会跳）。官方姿势点「零位」，过渡 3 秒，托着看：
   - 腿一条直线、脚板跟小腿垂直、左右对称、头平视。
   - 差一两度的：扭矩开着用滑块调正，点「校准这一颗」，基准选「零位 2048」。最可能要调的是踝和髋 roll，它们在折叠时是靠眼睛摆的。
6. 点「站」，看站不站得稳、左右对不对称。
7. 断电再上电，同一个姿势读数不变，说明偏移写进 EEPROM 了。

**21 号换新舵机的话**，校准前先按顺序做完：

1. 总线上只接新舵机，调试台「改 ID」改成 21
2. 转到 2048
3. 舵盘朝关节伸直的方向装，齿对不准取最近的
4. 开过流、过压保护（第 3 节）
5. 装回腿上后核 ±：扭矩关着用手掰，看 3D 转向

## 附：背景速查

- **ID**：20–24 左腿（髋 yaw / roll / pitch、膝、踝），30–34 颈 pitch、头 pitch / yaw / roll、嘴，10–14 右腿。1 Mbps，单线半双工，URT-2。
- **方向**：15 颗全 −1，2026-09-20 实机核过，存在 `directions.json`。
- **零点**：官方 2048 = 腿伸直站立（MJCF 关节全 0）。官方代码和策略不加补偿。
- **寄存器**：

  | 地址 | 内容 |
  |---|---|
  | 19 | 卸载条件：1 电压、2 磁编码、4 过热、8 过流、32 过载 |
  | 65 | 状态位，跟 19 同一套位 |
  | 28–29 | 保护电流，×6.5 mA |
  | 38 / 35 / 36 | 过流保护时间 / 保护时间 / 过载扭矩（%） |
  | 13 | 温度上限 |
  | 9–12 | 最小 / 最大角度限制 |
  | 31 | 位置偏移，BIT15 = 负 |
  | 48 | 转矩限制，1000 = 100%，SRAM |
  | 63 / 69 | 当前温度 / 当前电流（×6.5 mA） |

- HD-1910（固件 3.46）不认「扭矩开关写 128」这种中位校准，调试台用 0x0B。
